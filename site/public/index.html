Puis-je utiliser les sons dans un projet commercial ?

Oui. Les sons de la bibliothèque de base sont sous licence CC0 : YouTube, publicité, film, client, sans créditer.

Et sur Mac ?

Windows d'abord. La version macOS suit, avec la même application.

Comment proposer mes propres sons ?

Bientôt, directement depuis l'application. Chaque son sera vérifié avant publication. Et à terme, une partie des revenus d'Onde sera reversée aux créateurs, selon l'utilisation réelle de leurs sons.

Windows affiche « Windows a protégé votre ordinateur » : est-ce normal ?

Oui. Windows affiche ce message pour les logiciels qui ne sont pas encore signés par un certificat payant. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ». Le code d'Onde est public et chaque mise à jour est signée.
